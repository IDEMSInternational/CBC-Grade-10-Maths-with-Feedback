# Feedback tool

These files are copies of the feedback tool in [IDEMSInternational/IDEMS-case-studies](https://github.com/IDEMSInternational/IDEMS-case-studies) (`assets/feedback-tool/`), at commit `e55ce44`. Make changes there first and copy them here, so the copies stay the same.

The Action that handles feedback issues comes from the same commit: `.github/scripts/feedback.js` is `tools/feedback.js` there, and `.github/workflows/feedback.yml` runs it.

The book starts the tool with `assets/feedback-setup.js`.
